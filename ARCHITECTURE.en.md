## 1. Layered Architecture & Acyclic Dependency Boundaries

`ai-test-workbench v6.7` enforces a strictly acyclic four-layer architecture (verified by `test/unit/architecture-boundaries.test.mjs` and `test/unit/v630-architecture-and-extensibility.test.mjs`: `0` `src/scripts -> templates` inversions, `0` `src/**` circular imports, every `src/**/*.mjs <= 450` LOC, `0` strict `checkJs` errors, and `0` runtime npm dependencies):

1. **Layer 1 Core Leaf Utilities (`src/core/` + `src/types/`)**: Zero-dependency primitives (`version` with `SCHEMA_VERSIONS.codeMap: 5`, `outcome` with `CommandResult v2`, schema-validated `config` enforcing `AITEST-G101..G118`, `codeMap.engine`/`externalEngine`, `lockstepRules`, `memoryPatterns`, `parity`, `replayAllowedUpstreamHosts`, and `TEST_EGRESS_EXTRA_HOSTS`/`TEST_EGRESS_ALLOW_HOSTS`, zero-dep `stream-sse` Anthropic/OpenAI SSE parser, bounded-cache `glob`, linear-time `redact` v3 with VT ANSI stripping preserving `pinnedVersion` while redacting `pin`/`pincode`, `playwright-results`, `playwright-resolve`, `proc`, `i18n`).
2. **Layer 2 Authoritative Verification Kernel (`src/kernel/`)**: Single source of truth exported via `package.json#exports` (`.`, `./kernel`, `./app`, `./target-guard`, `./schema-validator`), housing immutable `TrustContext` (`src/kernel/gate/trust-context.mjs`), positive-cached Git discovery (`src/kernel/gate/git-utils.mjs`), 5-checkpoint differential oracle (`src/kernel/diff-oracle.mjs`), `SymbolTable`, governance policy sealing `.aitest/mcp.lock` and `.aitest/engine-manifest.json` (`src/kernel/gate/policy.mjs`), and extensible **18-rule `AITEST-G101..G118`** (`ctx.extraRules` + governance-locked declarative `qa/support/project-rules.json`), deterministically mirrored by transitive closure into `templates/playwright-qa/support/` via `scripts/sync-template-vendor.mjs` (byte-identity enforced in CI; see [ADR-0002](./docs/adr/0002-kernel-ssot-vendor-mirror-and-upgrade.en.md)).
3. **Layer 3 App Facade & Domain Subsystems (`src/app/index.mjs`, `src/{trust,explore,codemap,impact,perf,parity,corpus,replay,memory,verdict,mcp-hub,init,runner,agents,governance,heal}/` & root domain services)**: Stable `./app` facade isolating `scripts/` / `bench/` from internals (exporting Graph Provider SPI, `installGraphEngine`, `probeEngineHealth`, and `ENGINE_MANIFESTS`); provides unified polyglot monorepo auto-discovery (`discoverMonorepoSubProjects` across depth-1 and `src|apps|packages|services|modules` depth-2 plus Python `FastAPI`/`aiohttp`/`Flask`/`Starlette`/`Django`/`Pytest` descriptors), hosts **CodeMap v5.1** three-tier fusion (L0 Vue 3 single-object routers/TS generic HTTP/cross-file prefix helpers/`.cjs` + Python polyglot/TypeORM/DDL + Spring/MyBatis extractors + L1 pinned sidecar with `AITEST_DATA_DIR` / ephemeral tmpdir leak prevention + L2 anti-corruption normalizer), **Diff-Impact v3.1** (shared-`.git` monorepo diff remapping + Python `.py` reverse-import graph + `global-infra-guard` + `pipe-sharded-v1` projected index), dual-target 5-checkpoint parity (`src/parity/`), offline sanitized traffic corpus (`src/corpus/`), sealed external upstream replay cassettes (`src/replay/`), zero-plaintext shape-fingerprint clustering and service-chain/tenant diagnostics (`src/diagnose/`), toolified memory distiller & repo sweeper (`src/memory/` + `src/learn.mjs`), Human Seam Gatekeeper Card (`src/verdict/seam-card.mjs`), `upgrade --scope engines`, and `AITEST_RESULT_FILE` framed subprocess IPC.
4. **Layer 4 Interface Surface (`src/cli/` + `src/mcp/`)**: Per-command strict CLI option registry (including `map --engine/--query`, `mcp install-engine`/`engine-status` with targetless global inspection plus structured `USAGE_ERROR`/`WORKSPACE_NOT_INITIALIZED` recovery actions, `upgrade --scope engines`, `parity`, `corpus`, `learn`, and unified `--json` envelopes even on usage errors, exit codes `0/1/2/64`) and zero-runtime-dependency multi-protocol MCP server (strictly preserving **17 canonical tools** + 8 deprecated v5/v6.1 forwarding aliases, adding the read-only resource `aitest://project/{target}/graph-summary`, with boundary-guarded in-process read-only fast paths for `aitest_impact`, `aitest_report`, `aitest_doctor`, read-only `aitest_mcp_hub` including `engine-status`, and `aitest_diagnose(dryRun=true)`; see [ADR-0001](./docs/adr/0001-mcp-protocol-stack-and-zero-dep-kernel.en.md), [ADR-0005](./docs/adr/0005-mcp-surface-outcome-and-config.en.md), [ADR-0006](./docs/adr/0006-differential-parity-oracle-and-shape-fingerprints.en.md), and [ADR-0007](./docs/adr/0007-external-code-graph-engine.en.md)).

## 2. Project Isolation (`<repo>/qa/`) & Safe Upgrades

Each repository receives an isolated `<repo>/qa/` subproject with exact-pinned dependencies, `.aitest/template-manifest.json`, `.aitest/governance.lock`, `.aitest/mcp.lock`, `.aitest/engine-manifest.json`, `.aitest/runs/` ledgers, `.aitest/quarantine.json`, `specs/`, `tests/`, `knowledge/` (`code-map.json`, `SYSTEM_MAP.md`, and `graph-impact-index.json`), `impact-map.json`, `waivers.json`, `known-blockers.json`, `corpus/`, `fixtures/upstream-cassettes/`, and `reports/`. Host kernels and engine pins upgrade safely via 3-way hash diffing in `npx ai-test-workbench@6.7.0 upgrade --target <repo>` (and `--scope engines`). External graph sidecar binaries and caches are strictly isolated in out-of-workspace cross-platform short-path directories (supporting `AITEST_DATA_DIR` / `AITEST_CBM_*` migration, defaulting to Windows `%LOCALAPPDATA%\aitw\` with `%SystemDrive%\aitw-{rt,cbm}` owner-only ACL fallback, macOS `/private/tmp/aitw-rt-<uid>` `<= 60B`, and Linux `$XDG_CACHE_HOME/aitw/` forbidding WSL2 DrvFs `/mnt/*`), never placed under `<qaDir>/.aitest/`, and automatically skipped on ephemeral `os.tmpdir()` repos.

## 3. Default-Deny Security Guardrails (`src/kernel/target-guard.mjs` + `base.ts`)

1. **Production, Egress & 10-Hop Redirect Firewall**: Rejects `TEST_ENV=production|prod|live|online`, malformed URLs, and invalid `TEST_EGRESS_MODE` values fail-closed; Playwright `context.route`, `APIRequestContext`, `perf`, and `explore` enforce `maxRedirects: 0` with per-hop re-validation (up to 10 hops) against `TEST_ALLOWED_HOSTS` / `TEST_DENIED_ORIGINS` / egress allowlists, plus `TEST_ABORT_THIRD_PARTY_HOSTS`.
2. **Full-Channel Request Interception & Subprocess Env Isolation**: `tests/fixtures/base.ts` wraps `context.route`, `APIRequestContext`, `context.request`, and `page.request`, blocks Service Workers, distinguishes loopback sandbox default CRUD from strict shared-host read-only defaults, and both `src/runner.mjs` and `src/codemap/providers/cbm-client.mjs` apply an explicit env allowlist stripping `AITEST_HMAC_KEY*` / OIDC credentials from Playwright, target, and sidecar subprocesses.
3. **Default-Deny Explorer & Schema Inference (`src/explore/`)**: Blocks all non-`GET/HEAD/OPTIONS` HTTP requests, non-allowlisted WebSockets, and `navigator.sendBeacon`, while synthesizing candidate JSON Schemas from read-only GET responses (`specs/api-schemas.json`).
4. **Redaction v3, 8-Pillar MCP Hub & Native Sidecar Supply-Chain Lock (`src/core/redact.mjs` + `src/mcp-hub/catalog.mjs` + `src/mcp-hub/auditor.mjs`)**: Strips JSON secrets, JWTs, cloud tokens, PEM keys, DB credentials, and VT ANSI sequences; pins all 8-pillar external MCP presets (adding Pillar #8 `code-intelligence` with `codebase-memory-mcp@0.12.1`), enforces `--ui=false`, bans mutating `update/install` args, verifies local binary SHA-256 digests, sanitizes untrusted code metadata via `sanitizeUntrustedCodeMetadata`, and seals `.aitest/mcp.lock` and `.aitest/engine-manifest.json` under `.aitest/governance.lock`.
5. **MCP HTTP Security Boundary**: Defaults to `127.0.0.1`, validates exact `Host` (`421`/`403`), `Origin` (`403`), and `Content-Type: application/json` (`415`), creates sessions only on `initialize`, returns `404` on unknown sessions, bounds JSON-RPC batches, verifies Bearer tokens via `crypto.timingSafeEqual`, and intersects `--workspace-root` with client `roots`.

## 4. Four-Layer Fail-Closed Anti-Fake-Green Gate Kernel (`src/kernel/gate/`)

- **Layer 0 Governance Lock, Sticky T1 & Config Schema**: Opens a single frozen `TrustContext`; supports multi-machine `macs: { [keyId]: hmac }` and sticky T1 anti-strip markers; `aitest_init` only seals fresh unmodified templates; verifies SHA-256 across protected paths (including `.aitest/mcp.lock` and `.aitest/engine-manifest.json`) and JSON-Schema-validates `aitest.config.json` (including `codeMap` / `externalEngine`).
- **Layer 1 Static Gate**: Runs `tsc --noEmit` + `eslint-plugin-playwright` (banning skips, `.only`, `waitForTimeout`, `{ force: true }`, `test.fail()`, raw `request.newContext()`); fails closed (`blocked`) in CI or whenever `governance.lock && node_modules` exist without compilers.
- **Layer 2 Run Ledger & Waiver Gate**: Binds `results.json` to ULID `runId` and workspace input fingerprint (custom `--results` without `--expected-run-id` or `partialScope: true` ledgers block); enforces `maxSkipped=0` default and human-approved waivers (`<= 5`, `<= 14d` TTL).
- **Layer 3 SymbolTable, Lattice, Dieselgate & Cross-Directory Lockstep Guard**: Evaluates **18 standalone rules (`AITEST-G101..G118`)** using TypeScript AST, lexical scope stack, and `SymbolTable` (`G116` HTTP status equivalence, `G117` product-side Dieselgate detection, `G118` cross-directory lockstep sync gate, `G-08` `git mv` out-of-tests guard, plus governance-locked pure-JSON declarative `qa/support/project-rules.json`); see [ADR-0004](./docs/adr/0004-pluggable-ast-gate-and-fp-governance.en.md) and [ADR-0006](./docs/adr/0006-differential-parity-oracle-and-shape-fingerprints.en.md).
