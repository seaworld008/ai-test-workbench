This guide defines how **AI Test Workbench (v6.6.0)** connects its native orchestrator MCP, browser execution, pinned code-graph sidecar (`codebase-memory-mcp@0.12.1`), backend logs, metrics, crash reports, read-only databases, cache inspection, and **Living Code Map v5 (`knowledge/code-map.json` + `knowledge/SYSTEM_MAP.md` + `knowledge/graph-impact-index.json`)**.

## 1. The 8-Pillar Full-Link Read-Only MCP Topology

| Pillar | Built-in Presets (`npx ai-test-workbench@6.6.0 mcp add`) | Enforced Read-Only & Supply-Chain Guardrail (`npx ai-test-workbench@6.6.0 mcp doctor`) |
|---|---|---|
| **1. Native Orchestrator (`orchestrator`)** | `ai-test-workbench`, `gitlab` | Native `mcp-serve` (`stdio` / `/mcp` / `/sse`); `GITLAB_READ_ONLY_MODE=true` |
| **2. Browser / UI / CDP (`browser`)** | `playwright-test`, `chrome-devtools` | `TEST_ALLOWED_HOSTS` + `TEST_BLOCKED_ENDPOINTS` + `serviceWorkers: 'block'` |
| **3. Code Graph Intelligence (`code-intelligence`)** | `codebase-memory-mcp` (`v0.12.1` exact pin) | Enforces `--ui=false`, bans `update/install` args, verifies local binary SHA-256 & governance-sealed `.aitest/engine-manifest.json`, out-of-workspace short-path isolation |
| **4. Observability & Crashes (`observability`)** | `grafana`, `prometheus`, `loki`, `sentry`, `victorialogs`, `skywalking` | `mcp-grafana --disable-write`; `--readonly` & read-only tokens |
| **5. Database State Verification (`database`)** | `postgres-readonly`, `mysql-readonly`, `mysql` | Read-only SQL role; `ALLOW_INSERT/UPDATE/DELETE_OPERATION="false"`; `${ENV}` placeholders |
| **6. Middleware & Cache (`middleware`)** | `redis-readonly` | `redis-mcp-server --readonly` |
| **7. Performance & Load Testing (`performance`)** | `k6` (+ `npx ai-test-workbench@6.6.0 perf` Web Vitals & SSE TTFT) | Budget assertions in `perf-budget.json`; read-only GET/SSE benchmarks by default |

## 2. Living Code Map v5 & Diff-Impact v3 Loop (`explore` → `map` → `impact` → `run` → `diagnose`)

1. **`npx ai-test-workbench@6.6.0 map --target <repo> --engine auto`** fuses L0 zero-dep full-stack extractors (Spring `WebProperties` prefixes, Feign/Dubbo/RocketMQ/MyBatis XML/`BaseMapper<DO>`, Vue `crudFactory`/template components/dynamic routes, Next.js/React/Express/NestJS/FastAPI/Go/PHP/Prisma/Drizzle) with the optional pinned L1 `codebase-memory-mcp@0.12.1` sidecar, generating `schemaVersion: 5` `code-map.json`, `SYSTEM_MAP.md`, and the `<20ms` `pipe-sharded-v1` `graph-impact-index.json` (with fast cached `--query <symbol>`).
2. Every run increments `revision`, preserves runtime dynamic routes and historical defects, non-destructively refreshes `autoGenerated` rules inside `impact-map.json`, and exposes the read-only MCP resource `aitest://project/{target}/graph-summary`.
3. **Additive-Only Fail-Closed Diff-Impact v3 & Trace-Correlated Diagnostics (`npx ai-test-workbench@6.6.0 diagnose`)**: Global infrastructure edits trigger `global-infra-guard` full-suite fallback; `base.ts` passively captures `traceparent`, `x-trace-id`, `sw8`, and `eagleeye-traceid`, emitting `serviceChains`, `tenantAuthHints`, mapped frontend/backend source files, and ready-to-run Loki / VictoriaLogs / PromQL / Sentry / read-only SQL queries.
