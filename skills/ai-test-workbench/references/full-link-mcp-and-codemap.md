# 8 大支柱全链路 MCP 中枢与活体代码地图 v5 规范 (v6.6.0)

> [English Version](./full-link-mcp-and-codemap.en.md) · [SKILL.md](../SKILL.md)

本文档定义 **`ai-test-workbench` v6.6.0** 如何将浏览器端执行、原生编排、外部代码图谱侧车（`codebase-memory-mcp@0.12.1`）、后端日志、监控指标、异常追踪、只读数据库、中间件缓存、性能压测与活体代码知识图谱 v5（`knowledge/code-map.json` + `knowledge/SYSTEM_MAP.md` + `knowledge/graph-impact-index.json`）打通。

## 1. 8 大支柱全链路只读 MCP 架构

| 支柱域 | 内置预设 (`npx ai-test-workbench@6.6.0 mcp add`) | 强制只读与供应链护栏 (`npx ai-test-workbench@6.6.0 mcp doctor`) |
|---|---|---|
| **1. 原生编排中枢 (`orchestrator`)** | `ai-test-workbench`, `gitlab` | 原生 `mcp-serve`（`stdio` / `/mcp` / `/sse`），`GITLAB_READ_ONLY_MODE=true` |
| **2. 浏览器 / UI / CDP (`browser`)** | `playwright-test`, `chrome-devtools` | `TEST_ALLOWED_HOSTS` + `TEST_BLOCKED_ENDPOINTS` + `serviceWorkers: 'block'` |
| **3. 代码图谱智能 (`code-intelligence`)** | `codebase-memory-mcp` (`v0.12.1` 精确锁版) | 强制 `--ui=false`、禁 `update/install` 参数、校验本地二进制 SHA-256 与 `.aitest/engine-manifest.json` 治理锁、短路径工作区外隔离 |
| **4. 可观测与崩溃链路 (`observability`)** | `grafana`, `prometheus`, `loki`, `sentry`, `victorialogs`, `skywalking` | `mcp-grafana --disable-write`；`--readonly` 与只读权限 Token |
| **5. 数据库状态校验 (`database`)** | `postgres-readonly`, `mysql-readonly`, `mysql` | 只读 SQL 角色；`ALLOW_INSERT/UPDATE/DELETE_OPERATION="false"`；禁止硬编码密码 |
| **6. 中间件与缓存 (`middleware`)** | `redis-readonly` | `redis-mcp-server --readonly` |
| **7. 性能与压测 (`performance`)** | `k6` (+ `npx ai-test-workbench@6.6.0 perf` Web Vitals & SSE TTFT) | `perf-budget.json` SLO 门禁；默认仅对只读 GET/SSE 做基线 |
| **8. API 契约漂移 (`api-contract`)** | `openapi-contract` | 只读抓取 OpenAPI / Swagger Schema 校验契约一致性 |

## 2. 活体代码地图 v5 与 Diff-Impact v3 闭环 (`explore` → `map` → `impact` → `run` → `diagnose`)

1. **`npx ai-test-workbench@6.6.0 map --target <repo> --engine auto`** 融合 L0 零依赖全栈提取（Spring `WebProperties` 前缀、Feign/Dubbo/RocketMQ/MyBatis XML/`BaseMapper<DO>`、Vue `crudFactory`/模板组件/动态路由、Next.js/React/Express/NestJS/FastAPI/Go/PHP/Prisma/Drizzle）与可选 L1 锁版本 `codebase-memory-mcp@0.12.1` 侧车，产出 `schemaVersion: 5` `code-map.json`、`SYSTEM_MAP.md` 与 `<20ms` `pipe-sharded-v1` `graph-impact-index.json`；支持 `--query <symbol>` 秒级缓存组合检索。
2. 每次执行 `explore` / `run` / `perf` / `map` 均会自动递增 `revision` 并保留运行时动态路由与历史缺陷，非破坏式同步 `impact-map.json` 中的 `autoGenerated` 规则（保留手工规则），并提供只读 MCP 资源 `aitest://project/{target}/graph-summary`。
3. **Additive-Only Fail-Closed Diff-Impact v3 & Trace-ID 根因贯通（`npx ai-test-workbench@6.6.0 diagnose`）**：全局基础设施变更触发 `global-infra-guard` 自动回退全量；`base.ts` 自动捕获 `traceparent` / `x-trace-id` / `sw8` / `eagleeye-traceid`，在 `ai-diagnostics.md` 直接给出 `serviceChains`、`tenantAuthHints`、前后端源码路径与可复制的 Loki / VictoriaLogs / PromQL / Sentry / 只读 SQL 查询。
