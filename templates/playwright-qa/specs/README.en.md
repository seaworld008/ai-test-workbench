# Test Plans (`specs/`) — `__PROJECT_NAME__`

> [简体中文 (默认)](./README.md)

Store human-reviewable Markdown test plans generated by the Playwright **Planner** agent (or `npx ai-test-workbench@6.5.0 explore`'s `system-overview.md`) here before converting them into executable specs via **Generator**.

## Required Sections per Plan

1. **Scope & Requirement Link**: Issue/PRD reference and target environment.
2. **Test Roles & Preconditions**: Dedicated QA account roles and seed state (`tests/seed.spec.ts`).
3. **Scenarios**: Priority (`@critical`, `@smoke`), `@mutation` tag when modifying backend state, deterministic steps & explicit assertions, negative/RBAC/`0/1` boundary cases, and cleanup strategy.
4. **Open Questions**: List ambiguous requirements explicitly rather than guessing or normalizing bugs.
