# Test Plans (`specs/`) — __PROJECT_NAME__

Store human-reviewable Markdown test plans generated by the Playwright **Planner** agent in this directory before converting them into executable specs via **Generator**.

## Required Sections per Plan

1. **Scope & Requirement Link**: Issue/PRD reference and target environment.
2. **Test Roles & Preconditions**: Dedicated QA account roles and seed state (`tests/seed.spec.ts`).
3. **Scenarios**:
   - Priority (`@critical`, `@smoke`, normal)
   - Mutation tag (`@mutation` if backend state changes)
   - Deterministic steps & **explicit user-visible/API assertions**
   - Negative, permission, and boundary cases (`0/1` quota, duplicate submission, 4xx/5xx recovery)
   - Cleanup / reset strategy
4. **Open Questions**: Unclear requirements must be listed explicitly rather than guessed.
